Quantization

s = (max-min)/(2^b-1). Z = round(-min/s). x_q = clamp(round(x/s)+z, 0, 2^b-1). x_hat = s(x_q-z). In-range error <= s/2.

Adaptation

Scaling: log10 L = a + b log10 N (toy b = -0.0748/decade). SFT: loss on response tokens only. RLHF: E[r] - beta KL. LoRA: W0 + BA, r(d+k) params (128x fewer at 4096/16).

Serving

Step = max(compute, fetch+assemble). P99 over means. Capacity = tokensk/expertsfactor. Dispatch = tokenskd bytes one way. R(B) = B/(c0+c1 B). $/MTok = 1e6/R * $/hr / 3600.

Retrieval

Amortized = B/N + q. RRF = sum 1/(k+rank). Cascade = sum count*cost. Gate: delta >= -epsilon.

Scheduling

DRF share = max(demand/total). Straggler tax = (max-median)/median. Makespan via FIFO sim.

Evidence grades

measured > derived > stated > opinion. Never promote without the artifact.

Defense five

claim, evidence, baseline, failure, cost.
