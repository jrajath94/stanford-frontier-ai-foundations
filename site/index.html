How to use this system

Complete Mode. Work through each course in order. Lessons link forward and backward; shared concepts are taught once and referenced, not repeated.

Fast Mode. Start with the lessons marked for research-engineering relevance: Transformer internals, training, inference, distributed systems, post-training. Each lesson page links to its full source lecture.

Study rules. Mark lessons complete as you finish them; the sidebar tracks progress. Use search to jump to any concept. Every timestamp links to the exact moment in the original lecture.
