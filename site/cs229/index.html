CS229: Machine Learning

Instructor: Tengyu Ma, Chris Re · 36:59

The mathematical foundations of machine learning, taught for the era of foundation models.

This course is the classical core that the rest of this system builds on.

CS336 taught you how to build a language model. This course teaches you why the pieces work: the statistical principles behind regression and classification, the optimization behind training, the theory behind generalization, and the algorithms behind unsupervised learning and reinforcement learning. The Spring 2026 offering is distinctive: it ends where modern AI begins, with diffusion models, representation learning, LLMs, and RL for language models.

Lessons

Part I: Supervised learning

  1. Introduction — what ML is, the course map, prerequisites
  2. Supervised learning setup — LMS, gradient descent, normal equations
  3. Weighted least squares — probabilistic view, Newton’s method
  4. Exponential family and GLMs — the unifying framework
  5. Gaussian discriminant analysis — generative vs discriminative

Part II: Practical advice and deep learning

  1. Dataset splits and ML advice — bias-variance, regularization, debugging
  2. Neural networks 1: architecture — MLPs, activations, modern modules
  3. Neural networks 2: backprop — the chain rule at scale

Part III: Unsupervised learning

  1. K-means and GMM — clustering without labels
  2. EM, PCA, ICA — latent variables and dimensionality reduction

Part IV: Generative and foundation models

  1. Diffusion models — the generative engine behind image models
  2. Representation learning — pretraining, contrastive learning, RAG
  3. LLMs and next-token prediction — language modeling as ML
  4. Transformers and in-context learning — attention, MoE, prompting
  5. Attention variants — improving attention, efficiency details

Part V: Reinforcement learning

  1. RL basics and MDPs — Markov decision processes, value iteration
  2. Policy gradient — REINFORCE, PPO, RL for language models

Interview labs

  • Lab 1: Derivations by hand — normal equations, logistic gradient, backprop
  • Lab 2: Bias-variance in practice — diagnose and fix a failing model
  • Lab 3: EM from scratch — implement GMM clustering
