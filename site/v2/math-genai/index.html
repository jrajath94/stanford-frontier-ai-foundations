Mathematical Foundations of Generative AI

Course home for math-genai: ten units on the mathematics behind generative AI, from probabilistic generative modelling through variational methods, adversarial training, diffusion, score-based and autoregressive models, to LLM inference, quantization, and alignment. Each unit pairs a lesson page and answer keys with an interactive companion: a narrated, self-contained HTML artifact with worked numbers, interactive benches, and a wisdom index.

How to use this course

  1. Read the units in order. Each unit builds on the last: U05's ELBO returns in U07, U07's schedule returns in U08, U08's epsilon net returns in U09.
  2. Answer keys live in separate files, one per lesson. Attempt every exercise before you open the key.
  3. Each unit's interactive companion narrates the lesson with worked numbers, interactive benches, and a wisdom index. Every number carries its lesson section. Nothing is quoted from a lecture transcript (none exists for these units).
  4. The crash course compresses all ten units. The cheatsheet holds the formulas. Terms are fixed in the glossary.
